Concentration function

A metric measure space (mm-space) is a compact metric space (X,d) with a Borel probability measure μ.

For A∈B(X) and r>0, define the open neighborhood

Ar:={x∈X: d(x,A)<r}.

For θ∈(0,1], define

αX(r;θ):= sup A∈B(X), μ(A)≥θ {1−μ(Ar)}, αX(r):= αX(r;12).

MEASURE CONCENTRATION · 03

Lévy family

Let {(Xn,dn,μn)} n≥1 be a sequence of mm-spaces.

The following statements are equivalent:

  1. {(Xn,dn,μn)} n≥1 exhibits the measure concentration phenomenon.
  2. {(Xn,dn,μn)} n≥1 is a Lévy family.
  3. αXn(r)→0 asn→∞, for every fixedr>0.

Related work

Michel Ledoux, The Concentration of Measure Phenomenon.

Let mf be a median of a 1-Lipschitz function f:X→R. i.e., μ({f≤mf})≥12, μ({f≥mf})≥12.

Set–function equivalence (Chapter 1)

A 1-Lipschitz function is a map

f:X→R, |f(x)−f(y)| ≤d(x,y).

For every r>0,

αX(r) ≤ sup ‖f‖Lip≤1 μ(|f−mf|≥r) ≤ 2αX(r).

Ledoux’s estimate on the sphere (Chapter 2)

For every 1-Lipschitz f:Sn→R, r>0 there exist universal constants C,c>0 such that

σn (|f−mf|≥r) ≤ Ce−cnr2.
Fixed r>0 → Ce−cnr2→0asn→∞ → {(Sn,dgeo,σn)} n≥1 is a Lévy family
